    Testing & Accessibility

    Keyboard test
    1. Press Tab repeatedly and confirm every control receives a visible focus outline.
    2. Use Enter or Space to activate buttons.
    3. Complete and submit the form using only the keyboard.
    Validation test
    1. Leave a required field empty and submit.
    2. Enter an invalid email or phone number.
    3. Leave a dropdown unselected.
    4. Leave a required checkbox unchecked.
    5. Correct each value and confirm the error disappears.
    Automated accessibility test

    Open Chrome DevTools → Lighthouse → Accessibility, and separately inspect the Accessibility tree under Elements → Accessibility.
